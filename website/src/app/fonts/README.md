# Cabinet Grotesk

The display and body face is Cabinet Grotesk by Indian Type Foundry, distributed by Fontshare.

- Source: https://www.fontshare.com/fonts/cabinet-grotesk
- License: ITF Free Font License, free for personal and commercial use.
- Files in this directory are the 400, 500, 700, and 800 normal weights, self-hosted so the site makes no runtime font request.

Geist Mono is loaded at build time through `next/font/google` and self-hosted by Next.js.
